# ZAAR Kashmir — Concept storefront

Responsive storefront concept for a fictional Kashmiri saffron, kahwa, and artisan goods brand.

- `index.html` — page markup
- `css/styles.css` — responsive storefront styles
- `js/main.js` — demo bag and signup interactions
- `assets/` — folders for locally licensed images, icons, and fonts

External Unsplash images and Google Fonts currently load from URLs in the page. Demo interactions do not submit real orders or store customer data. This is not an installable Shopify theme.
