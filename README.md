## Preview
Open `zaar/index.html` locally, or enable GitHub Pages from the repository root to publish this static portfolio.

The ZAAR page is a front-end concept, not a Shopify theme: cart and signup are demo-only, with no live checkout, payments, inventory, or Shopify connection. It loads stock imagery and Google Fonts from external URLs while online. Replace these with client-approved content before production.

Label speculative work as a concept/demo. Publish client names, work, and testimonials only with permission.
